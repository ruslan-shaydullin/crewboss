# Changelog

## 0.1.0-alpha.1

First packaged experimental release.

- Contributor setup, required CI, contribution guides and private security reporting.
- Explicit runtime configuration, configurable service/provider paths and sandbox preflight.
- Required API authentication, explicit CORS origins and authenticated fetch streams.
- Honest GitHub failure handling, confirmed terminal transitions, reviewer deliverables
  and blocked queue recovery.
- Local fixture demo and a reproducible runtime archive with checksums.

The agent runtime targets Linux x86_64 with systemd and nsjail. The dashboard and
fixture demo also run on macOS. This alpha does not promise a stable API or
unattended production operation; see the installation guide for verified checks.
