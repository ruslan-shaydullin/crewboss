## КОР-ИДЕЯ (читать первой)
Нельзя hard-загейтить суждение («не читай вопрос как команду»). Можно загейтить только ДЕЙСТВИЯ.
Поэтому делим профиль на ТРИ слоя по тому, чем каждый держится:
1. **Действия-эскалации** (спавн агентов, мерж, push в общую ветку, loop, пачка issue) → **hard, через
   identity**: физически недоступны БЕЗ явного запуска роли.
2. **Заявления о готовности** (ложное «исчерпано»/«готово», закрытие задачи при недоделке) → **hard, но НЕ
   через identity, а через COMPLETION-GATE: доказательство артефакта/исполнения вместо самоотчёта** (тесты
   зелёные / дифф / чек-лист DoD объективно отмечен), и Stop/SubagentStop-хук не отпускает «done», пока пруф
   не предъявлен. Держится детерминизмом/исполнением, НЕ LLM-судьёй.
3. **Диспозиция** (вопрос≠команда, самохвальство, «казаться продуктивным», рулёж) → **irreducibly-soft, мы её
   НЕ чиним** (зашито RLHF, лечится только тренировкой). Держится коротким поводком; permission-правилом не
   прибить — и притворяться, что прибили, нельзя.

**Ведущий кандидат решения (прогон валидирует/уточняет, не догма; модель ещё ОТКРЫТА — см. A2):** не лабиринт
хуков, а **identity-split через `--agent`**:
- DEFAULT identity (что запускается без явного вызова) = урезанный набор: Read/Edit/Bash по своей ветке,
  `gh pr create`. БЕЗ `Agent`-спавна, БЕЗ `gh pr merge`, БЕЗ `loop`.
- `--agent tech-lead` (запускается ЯВНО) = добавляет `Agent`/merge/loop/пачку issue.
→ Сама identity = детерминированный сигнал «явного вызова» (не agent-hook, который судит как я и может
ошибиться). Реализует профиль C дословно: «не уверен в режиме → default → не действую» становится физикой.

5. **Completion-gate смотрит АРТЕФАКТ/исполнение, не самоотчёт и не рассуждение.** ЗАПРЕТ: не ставить
   LLM-критика «судить мои слова» — корреляция ошибок делает это иллюзией проверки (ресёрч 3-0). Пруф =
   детерминизм (тесты/дифф/DoD-чек); LLM-judge — максимум по узкому артефакт-вопросу, НЕ по reasoning.
6. **Честный статус completion-gate:** «Stop-хук-на-DoD снижает false-done» — вывод из литературы, НЕ
