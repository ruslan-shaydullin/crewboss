## 5. Что ЯВНО НЕ делаем в v0 (дисциплина тонкого референса)

- gh-aw token-split / GitHub Actions-обвязка (опциональный security-апгрейд, не reliability).
- Vendor-agnostic абстракция / поддержка Cursor/Codex (только язык спеки нейтральный).
- CLI-инсталлер (хватает «скопируй файлы»).
- Multi-level спавн / зависимость от agent-teams (самая хрупкая поверхность).
- Тяжёлый фреймворк. Спека — продукт, код — пруф.

## 7. Честные риски

1. **Absorption.** Anthropic катит agent-teams/hooks; completion-gate может уехать в
   натив. Митигация (она же наш выбор): спека-словарь переживает мехизмы — держим
   altitude на таксономии, не на хук-скриптах.
2. **Демо-friction.** Board-демо требует реальный `gh` + sandbox-репо — выше порог
   «попробовать». Митигация: запись, чтобы смотреть можно без прогона.
3. **Over-claim self-own.** Проект про честность — если сами over-claim'нём
   («гейт непробиваем»), репутационный удар вдвойне. Воркстрим H закрывает.
4. **Vendor-churn.** Экспериментальные фичи за флагом ломаются между релизами. Pin + политика версий.
