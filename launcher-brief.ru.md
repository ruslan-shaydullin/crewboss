# Лаунчер — кратко и простыми словами

> Это «для меня» — что и как делаем, без жаргона. Подробная версия для работы — [launcher-design.ru.md](launcher-design.ru.md).
> Модель: эфемерные **nsjail-песочницы на Linux-хосте**, агенты через `claude -p` на **токене подписки (OAuth)**, лаунчер — тупой супервизор + детерминированная очередь.
> Дизайн прогнан через red-team (35 находок, 5 блокеров) — здесь уже исправленная версия.

## Что это и зачем
Лаунчер — **пульт управления флотом агентов**. Смотрит на борд (GitHub-issues), берёт готовые задачи и запускает по агенту на каждую — каждого отдельной изолированной сессией. Сейчас это голый скрипт; делаем умный автономный пульт.

## Два слоя (раньше планировали три — мозг оказался не нужен)
1. **Рельсы (мотор)** — маленький проверенный скрипт. Считает «кто имеет право» + держит лимиты + **сам планирует очередь** (приоритет, кэпы, роутинг ролей) — но **всё детерминированно, без ИИ**. Раньше думали посадить сюда скрытый LLM-«мозг»; red-team подтвердил твою же мысль: **на ≤3 слотах мозг бесполезен и сам жрёт бюджет** → выкинули. Очередь сортирует jq, не нейросеть. Никакого un-gated мозга.
2. **Панель (TUI)** — показывает флот и нажимает кнопки. Своей логики «кого запускать» нет.

## Как запускаются агенты
- **Каждый агент = `claude -p` в лёгкой песочнице nsjail на Linux-хосте.** Один процесс на задачу, сделал — умер (эфемерно). Не контейнеры, не субагенты.
- **На токене подписки (OAuth), не на платном API.** Проверено по докам: `claude -p` (НЕ `--bare`) + `CLAUDE_CODE_OAUTH_TOKEN` без `ANTHROPIC_API_KEY` = работает на подписке. Каждый — на своей личной подписке (не Claude-team).
- **nsjail вместо Докера** — без образа, без демона. Изоляция: песочница по умолчанию пустая, видно только прибинженное (репо-копия + toolchain). **Это третий слой защиты** (host/CPU/память/ФС), но честно: он **не** мешает злоупотреблять токеном в разрешённом канале и не ловит эксфильтрацию — это неустранимо.

## Что red-team поймал (и что мы чиним)
5 блокеров, без которых флот не стартовал бы ни разу:
1. **git push уходил в никуда** — `clone --local` ставит origin на локальное зеркало → push не на GitHub. Фикс: явно ставим push-remote на github.
2. **Зеркало не свежело** — нужен `git clone --mirror`, не `--bare`.
3. **В песочнице нет сети** — nsjail по умолчанию даёт только loopback. Egress — это **host-side фильтрующий прокси** с allowlist, а не «настройка jail».
4. **OAuth-refresh блокировался** — токен живёт ~60 мин, рефреш идёт на `console.anthropic.com` → этот хост ОБЯЗАН быть в allowlist (+ `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`).
5. **Биллинг устарел** — с 15.06.2026 это **месячный долларовый пул** ($20 Pro / $100 Max5x / $200 Max20x по API-ценам), а не «5-час окно». Бюджет-гард считает % от пула.

Плюс закалка: токены не текут в логи (redaction), узкий fine-grained токен, reconciler переживает reboot, seccomp в профиле, один-инстанс-лок, одна-ФС для зеркала и работ.

## Какие роли (все)
- **executor / tech-lead / analyst / task-helper** — эфемерные, в jail, из очереди, без чата.
- **boss — особый: живая resumable-сессия**, управляется **из лаунчера** (не открываешь терминалы руками), чат, code-blind → без jail. Не в автономной очереди.

## Что пульт должен уметь
1. **Сам подхватывает задачи** в очередь по приоритету, спавнит до лимита. Тыкать не надо.
2. **Все роли**; boss — кнопкой «открыть/продолжить чат».
3. **Лимит каждой роли — настраивается**; рельсы держат жёстко.
4. **Живая панель агентов** — кто над чем, ветка, фаза, время.
5. **3 вида**: компактный · таблица · подробный.
6. **Кнопки**: запустить · пауза · убить · одобрить план · открыть boss.
7. **Настройки**: лимиты, бюджет (% от $-пула), частота опроса, ретраи, авто-boss/ассистент.
8. **Чартерные ветки**: каждый чартер в `charter/N`, в конце один PR на ревью всего чартера.
9. **Статус ревью**: какие PR готовы (2 из 3), какие ждут.
10. **Бюджет-гард**: сумма стоимости прогонов, стоп на N% пула; 429/исчерпание ловим отдельно.
11. **Безопасность**: kill-switch, бюджет-кап, один-инстанс-лок, агенты переживают закрытие панели.

## Как делать
- **Рельсы — bash** (спавн nsjail + редирект-с-redaction + `kill -0` + детерминированный планировщик-jq).
- **Образа нет** → `crewboss provision`: toolchain на хост + nsjail-профили + bare-mirror. `doctor` проверяет: Linux, user-namespaces (hard-fail если нет), nsjail+seccomp, push-URL на github, одна-ФС, токены.
- **Панель**: сначала контракт (`status.json`+лог), простая панель, при желании потом Go — не трогая рельсы.

## Что осталось решить
1. Панель: bash+tmux или Go (или «контракт сначала» — рекоменд.).
2. ТУЗ-бот сейчас? (для «2 из 3» на мерже).
3. Авто-boss/авто-ассистент — opt-in? (рекоменд. default человек).
4. Где Linux-хост (свой VPS/облако) — от этого user-namespaces и egress.
5. Тариф подписки под флот ($20 Pro = единицы прогонов Opus / $200 Max20x).

## Честно про риск
- **Un-gated мозга больше нет** (выкинули LLM-диспетчер) → граница доверия только детерминированная + гейты.
- nsjail держит host/network/resource (и kernel-поверхность — если задан seccomp), **но не** злоупотребление токеном в разрешённом канале и не эксфильтрацию — защита = узкий токен + four-eyes на мерже + egress-лог.
- Подписка ограничивает флот (доллары в месячном пуле) — бюджет-гард несущий.
- Авто-флот на личной подписке — серая зона fair-use (помечено).
- Мерж/закрытие гейтятся людьми + branch protection, не лаунчером.
